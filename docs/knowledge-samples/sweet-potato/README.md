# 红薯专题知识库样例

这组文件用于测试「智能体控制台 → 知识库」在红薯场景下的上传、解析和检索，覆盖 Markdown、TXT、DOCX、PDF 和 GB18030 编码。

| 文件 | 格式 | 内容 | 建议测试点 |
|---|---|---|---|
| `红薯品种选择与薯苗处理.md` | Markdown / UTF-8 | 品种用途、种薯挑选、温汤浸种、高剪苗 | 标题与正文命中 |
| `红薯育苗与栽插技术要点.txt` | TXT / UTF-8 | 苗床、排种、炼苗、栽期、密度、栽插方法 | 纯文本解析 |
| `红薯水肥管理与控旺.docx` | Word / DOCX | 需肥比例、基肥/追肥表、水分表、控旺 | 段落 + 表格解析 |
| `红薯主要病虫害识别与防治.pdf` | PDF / 中文 | 黑斑病、茎线虫病、根腐病、病毒病、地下害虫 | 中文 PDF 提取 |
| `红薯生长阶段与管理日历.docx` | Word / DOCX | 五个生育阶段与关键管理节点 | 表格解析 |
| `红薯收获与储藏_GB18030.txt` | TXT / GB18030 | 收获适期、预贮愈合、窖藏温湿度 | 非 UTF-8 编码回退 |

## 上传方法

1. 打开 http://localhost:5173
2. 侧栏「助农手」→ 选择红薯地块的智能体 →「知识库」
3. 把文件拖进上传框，或点击上传；每个文件 ≤5MB
4. 上传后应能看到文档标题、字数、片段数和来源
5. 在「检索测试」里输入 `黑斑病怎么防治`，应命中 PDF 文档

## 已验证

- 6 份资料都能被后端解析器提取（走 `/api/agent/document`，不落库）
- DOCX：646 字、2 个片段；PDF：706 字、2 个片段；GB18030 TXT：649 字、2 个片段
- PDF 为 Chrome 导出，中文提取正常；DOCX 表格能进入正文
- `eval-set.json` 只用于检索评测，**不要上传**；上传 6 份资料后可用它调用知识库评测接口
