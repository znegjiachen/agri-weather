# 水稻品种选择与种子处理

## 一、品种选择
- 根据当地有效积温选择生育期合适的品种，避免越区种植导致抽穗迟、灌浆不足。
- 优先选择通过审定、适合本地稻区的品种，关注稻瘟病、白叶枯病、褐飞虱等抗性。
- 双季稻区注意早稻、晚稻生育期衔接；再生稻选择再生能力强的品种。
- 米质、抗倒性和耐寒性根据当地市场与气候条件综合考虑。

## 二、种子处理
1. 晒种 1-2 天，提高种子活力和发芽整齐度，避免在水泥地面高温暴晒。
2. 风选、筛选去除瘪粒和杂质，种子纯度、净度符合用种要求。
3. 浸种前先做发芽试验；常规稻和杂交稻的浸种时间不同，按品种说明操作。
4. 药剂浸种：可选用咪鲜胺、氰烯菌酯等登记药剂，严格按标签浓度和浸种时间使用，预防恶苗病、稻瘟病等种传病害。
5. 催芽温度：破胸期 30-32 摄氏度，破胸后降至 25-28 摄氏度，芽长以 2-3 毫米为宜，避免高温烧芽。
6. 播种前摊晾炼芽，使芽谷适应常温，避免直接播入低温秧田。

## 三、注意事项
- 药剂浸种后充分清洗，避免药害；不同药剂不要随意混配。
- 播种量与秧龄、移栽方式配套，机插秧一般比手插秧播种密度高。
- 种子处理记录留档，便于追溯。
