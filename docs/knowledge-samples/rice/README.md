# 水稻专题知识库样例

这组文件用于测试「智能体控制台 → 知识库」的水稻场景，覆盖不同格式和不同农事环节。

| 文件 | 格式 | 内容 |
|---|---|---|
| `水稻品种选择与种子处理.md` | Markdown / UTF-8 | 品种选择、晒种、浸种消毒、催芽 |
| `水稻育秧与移栽技术要点.txt` | TXT / UTF-8 | 秧田准备、播种、炼苗、适龄移栽 |
| `水稻水肥管理与晒田.docx` | Word / DOCX | 分蘖肥、穗肥、晒田判断、阶段管理表 |
| `水稻主要虫害识别与防治.pdf` | PDF / 中文 | 稻飞虱、稻纵卷叶螟、二化螟、安全用药 |
| `水稻低温冷害与倒伏应对_GB18030.txt` | TXT / GB18030 | 低温冷害、倒伏原因与处理 |
| `水稻收获与烘干储藏.md` | Markdown / UTF-8 | 收获适期、机械收获、烘干、储藏 |
| `水稻生长阶段与管理日历.docx` | Word / DOCX | 从播种出苗到灌浆成熟的阶段管理表 |

## 建议测试

1. 上传全部 7 个文件，确认文档列表显示字数、片段数和来源
2. 检索测试：
   - `稻飞虱怎么防治` → 《水稻主要虫害识别与防治》
   - `什么时候晒田` → 《水稻水肥管理与晒田》
   - `低温冷害怎么防` → 《水稻低温冷害与倒伏应对_GB18030》
   - `水稻什么时候收获` → 《水稻收获与烘干储藏》
3. 在对话里问「水稻分蘖期怎么管」，检查回答是否引用知识库并给出阶段管理建议

## 已验证

- 7 个文件全部上传成功，解析字数 331–562 字，各自生成 1 个片段
- DOCX 表格、中文 PDF、GB18030 TXT 均能正常提取
- 标题命中与正文关键词命中都能召回（例如「什么时候晒田」能召回《水稻水肥管理与晒田》）

> 内容为演示用农业技术摘要，实际生产请以当地农技部门发布的品种布局、测土配方和病虫情报为准。
