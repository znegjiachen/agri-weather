# 知识库测试文件

这些文件用于验证「智能体控制台 → 知识库」的上传、解析和检索能力。

| 文件 | 格式 | 建议测试点 |
|---|---|---|
| `水稻稻瘟病防治指南.md` | Markdown / UTF-8 | 文本解析、标题、片段切分 |
| `玉米螟综合防治.txt` | TXT / UTF-8 | 纯文本解析 |
| `小麦赤霉病防治技术.docx` | Word / DOCX | 段落 + 表格解析 |
| `柑橘黄龙病识别与防控.pdf` | PDF（Chrome 导出） | PDF 中文提取 |
| `蔬菜灰霉病防治_GB18030.txt` | TXT / GB18030 | 非 UTF-8 编码自动回退 |

## 水稻专题

`rice/` 目录下另有 7 份水稻专题文档，覆盖品种与种子处理、育秧移栽、水肥晒田、主要虫害、低温冷害与倒伏、收获储藏、生长阶段日历。详见 [rice/README.md](rice/README.md)。

## 使用方法

1. 打开 http://localhost:5173
2. 侧栏「助农手」→ 选择智能体 → 「知识库」
3. 把文件拖进上传框，或点击上传；每个文件 ≤5MB
4. 上传后应能看到文档标题、字数、片段数和来源
5. 在「检索测试」输入 `稻瘟病怎么防治`，应优先命中《水稻稻瘟病防治指南》

## 已验证结果

- 五种格式都能解析：Markdown、TXT、DOCX（含表格）、中文 PDF、GB18030 TXT
- 字数：水稻 473、玉米螟 342、小麦 345、柑橘 413、蔬菜 223
- 检索「稻瘟病怎么防治」命中《水稻稻瘟病防治指南》
- 用浏览器上传中文文件名正常；用 curl/命令行直传中文文件名时可能因终端编码显示为乱码，不影响浏览器端使用

> 这些是测试用示例资料，实际使用时请替换为本地农技站或种植规范中的正式文档。
