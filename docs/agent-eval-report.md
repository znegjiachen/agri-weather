# 助农手 Agent 模拟评测报告

## 评测目的

验证助农手在**真实后端数据 + 真实 DeepSeek 模型**下，是否能：

1. 正确选择农事工具
2. 结合地块、作物、生育期回答
3. 给出可执行的农事建议
4. 在信息不足或阶段不匹配时保持谨慎

说明：这是**模拟问答测试**，不是田间试验，也不代表产量效果。

## 评测环境

- 时间：2026-11-06
- 部署地址：`http://47.96.25.53`
- 模型：DeepSeek `deepseek-reasoner`
- 天气：Open-Meteo 实时/7 日预报
- 数据：1 块测试水稻田，种植日期 2026-05-01，已进入收获期
- 方式：调用 `/api/agent/chat`，记录工具轨迹、轮数、耗时和回答

## 场景与结果

| # | 用户问题 | 实际调用工具 | 轮数 | 耗时 | 结果 |
|---|---|---|---:|---:|---|
| 1 | 我有几块地？分别种了什么？ | `list_farmlands` | 2 | 3.9s | 正确列出 1 块地及作物、播期、当前阶段 |
| 2 | 明天适合给这块水稻打药吗？ | `get_weather`、`get_operation_advice` | 2 | 7.1s | 识别降雨 20.5mm、风速 20km/h，明确回答不适合打药 |
| 3 | 这块水稻现在是什么生长阶段？ | `get_crop_stage`、`get_farmland_detail` | 2 | 3.7s | 判断为收获期，并提示已种植约 190 天、收获偏晚 |
| 4 | 未来几天有冻害或大风风险吗？ | `check_alerts`、`get_weather`、`get_operation_advice` | 3 | 11.7s | 发现低温和霜冻预警，结合收获期说明影响 |
| 5 | 水稻稻瘟病怎么防治？ | `get_weather`、`get_crop_stage`、`get_operation_advice`、`check_alerts` | 2 | 14.1s | 先判断已过防治窗口，不建议此时打药，给出当前阶段建议 |

**结果：5/5 场景均正确调用了相关工具，没有出现编造天气或跨地块数据。**

## 这个测试能说明什么

- Agent 不是纯聊天：它会真实调用天气、地块、作物阶段、预警和农事建议工具
- 回答会受地块和生育期约束，不是通用模板
- 工具权限有边界，无法读取其他用户地块
- 流式轨迹可展示“它查了什么”

## 局限

1. 仅为模拟问答，不是真实农户长期使用
2. 只覆盖 1 块地、5 个问题，样本较小
3. 模型输出存在随机性，同一问题措辞可能变化
4. 未做人工 5 分制盲评，也没有工具选择准确率的统计置信区间
5. 本轮未上传自定义知识库文档，RAG 引用未在此场景中体现
6. 没有田间产量、农药减量等效果数据
